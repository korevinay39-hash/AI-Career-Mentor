# 🤖 AI Career Mentor

AI Career Mentor is an AI-powered career guidance application that provides
personalized career recommendations, learning guidance, and progress tracking.

## 🚀 Tech Stack

- Python
- Streamlit
- LangChain
- Ollama
- Qwen 2.5 3B
- SQLite

## ✨ Features

- 👤 Create and manage career profile
- 🎯 Personalized career guidance
- 📚 Learning recommendations
- 🤖 AI-powered responses
- 📈 Track learning progress
- 💻 Run the AI model locally using Ollama
